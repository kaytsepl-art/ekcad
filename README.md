# AI Isometric Image to 3D WebGL Studio

Consolidated Vite + React + Three.js delivery for local testing and deployment.

## Quick start
```bash
npm install
npm run dev
```

## Production check
```bash
npm run build
npm run preview
```

## Included
- Procedural 2.5D Canvas renderer.
- Multi-object Three.js preview.
- Buildings, trees, hedges, grounds and courtyard SceneGraph.
- Object selection synchronization.
- SceneGraph validation and JSON view.
- Eight startup smoke tests.
- Undo/Redo history test transaction.
- Downloadable JSON test report.
- API, provider, environment and deployment specifications.

See `docs/FEATURES.md`, `docs/API_SPEC.md`, `docs/TEST_PLAN.md` and `docs/CHANGELOG.md`.
